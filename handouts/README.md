# Exoplanet Simulation Handouts

Four guided-inquiry lab handouts for intro-college astronomy, about two hours each, one for each
OpenLyceum exoplanet simulation. Students work in pairs at a computer.

This folder is tracked by the OpenLyceum workspace repository. Student sheets, instructor keys,
Word exports, figures, and the tools below are versioned together. Generated `_build/` and
`node_modules/` directories stay ignored.

| Folder | Simulation | Handout title |
|---|---|---|
| `StellarWobble/` | <https://openlyceum.github.io/StellarWobble/> | Weighing a Planet You Cannot See (radial velocity) |
| `TransitHunter/` | <https://openlyceum.github.io/TransitHunter/> | Finding Planets by Their Shadows (transits, real Kepler/TESS data) |
| `ExoplanetsDatabase/` | <https://openlyceum.github.io/ExoplanetsDatabase/> | What the Archive Can and Cannot Tell Us (selection effects) |
| `HabitabilityLab/` | <https://openlyceum.github.io/HabitabilityLab/> | What Makes a Planet Habitable? |

A natural order is StellarWobble → TransitHunter → ExoplanetsDatabase → HabitabilityLab. Each
handout stands alone, but later ones refer back to earlier ones (minimum mass, radius valley,
selection effects). The ExoplanetsDatabase handout can replace the earlier Claude doc *Exploring
Exoplanets with the NASA Exoplanet Archive*. Its first part overlaps that doc on purpose.

## What is in each folder

- `handout.md`: the student sheet (no timing; American English). It has predictions, guided steps
  naming the controls as the simulation labels them, data tables, and a synthesis section.
- `answers.md`: the instructor key: expected values, sample explanations, suggested pacing and what
  to cut, common misconceptions, and notes on the simulation's own spellings.
- `handout.docx`, `answers.docx`: Word versions, built from the Markdown (see below).
- `svg/`: diagrams drawn for the handout (generated by `tools/svg-<sim>.mjs`).
- `img/`: screenshots of the simulation in its projector (light) color profile. Files starting with
  `key-` are used only in `answers.md`.

## Convert to Word

```bash
tools/md2docx.sh StellarWobble/handout.md          # → StellarWobble/handout.docx
tools/md2docx.sh StellarWobble/answers.md out.docx  # choose the output name
tools/md2docx.sh --all                              # every handout.md and answers.md
```

Needs `pandoc` (3.x) and either `inkscape` or `rsvg-convert`. The script converts each SVG to a
192-dpi PNG so diagrams show in every version of Word. It also turns `<br>` answer space into blank
lines, and uses `tools/reference.docx`, which adds table borders and room to write in table rows.
Delete `tools/reference.docx` to rebuild it from pandoc's default. For a PDF, open the .docx in
Word or LibreOffice, or run `soffice --headless --convert-to pdf handout.docx`.

## Regenerate figures, screenshots and answer numbers

All tools run with Node 26 (`nvm use 26`) and use the simulations' own `node_modules` (Playwright).

```bash
# Diagrams
node tools/svg-stellarwobble.mjs        # likewise svg-transithunter, svg-exoplanetsdatabase, svg-habitabilitylab

# Screenshots: start the sim's dev server on the port named in tools/shots-<sim>.json, then
(cd ../StellarWobble && npx vite --port 5191) &   # TransitHunter 5192, ExoplanetsDatabase 5193, HabitabilityLab 5194
node tools/screenshots.mjs tools/shots-stellarwobble.json [shotName]

# Answer-key numbers (from each sim's formulas and bundled data)
node tools/answers-stellarwobble.mjs     # likewise for the other three

# Checks: image links resolve, SVGs have <title>/<desc>, bold control names exist in the sim's strings
node tools/check.mjs
```

The screenshot script drives each simulation through its keyboard-accessible controls (see the
comment at the top of `tools/screenshots.mjs`). Random elements (noise in Stellar Wobble's
Observatory, the random sky in Transit Hunter) change on every run.

## Simulation wording

The handouts use American spelling throughout. On 2026-11-06 the simulations' English labels were
changed to American spelling too ("Center on the far side", "Color key", "Color by", "Energy per
square meter", "Water vapor", …) in StellarWobble, TransitHunter, ExoplanetsDatabase and
HabitabilityLab (pushed to `main` and deployed), so the labels the handouts quote match the live sites.

## Correctness updates (2026-11-06)

HabitabilityLab, ExoplanetsDatabase, and TransitHunter handouts and instructor keys were updated
with the scientific corrections: tidal-lock times and timeline resolution, archive mass limits
and measured-only counts, numerical pure-iron guides, and brightness binning. The snapshot's
6,464 planets and original values are unchanged; limit flags were restored with value-drift
validation. Regenerate the Word files after changing Markdown, and regenerate relevant
screenshots after changing a simulation. Handout changes are pushed with the workspace repository;
they are not published by a sim push.
